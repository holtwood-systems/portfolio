# 2026-11-05 RTX 4090（sm_89）基线批次

- **tiny-llm**：修复 CUDA arch 默认守护失效——`check_language(CUDA)` 预置
  `CMAKE_CUDA_ARCHITECTURES=52` 使 `if(NOT DEFINED)` 永不命中，nvcc 12.8 产出
  的 compute_52 PTX 被驱动 550（CUDA 12.4 UMD）拒绝 JIT，全部自研 kernel
  静默未启动（compute-sanitizer 实锤 error 222）。修复后原生 sm_89 门禁
  **252/252 通过、0 skip**（首次 251/252 系隔壁进程占 42.7GB 的环境 OOM，
  失败日志一并入库）。RTX 4090 decode 基线：graphs TPOT 2.267ms / 441 tok/s；
  ncu 因 `ERR_NVGPUCTRPERM`（宿主 profiling 权限）不可用，kernel 归因改用
  仓内 cudaEvent 基准，LM head 282µs；DPA 30 shape 点全 bitwise 等价。
- **paged-serving**：真实 tiny-llm 后端在 RTX 4090 完成 closed-loop
  serving 两包：首包受外部 42.7GB 显存占用干扰，c1/c4/c8 未收敛（保留为
  干扰证据）；独占复测 c1/c2/c4/c8 **全部收敛**，吞吐 ~300 tok/s 饱和，
  TPOT 2.63→20.38ms 随并发线性。另发现 build.rs 只声明 `-lcudart` 不给
  搜索路径的 toolchain 缺口，proposed 笔记已入库、修复留待后续。
- **kvtier**：原生 Linux（非 WSL2）+ RTX 4090 完成 8 轮单卡 L2 回载基线：
  **`hicache-io-backend kernel` 无需 PR #43375 补丁即可工作**——WSL2 的
  registered host/device 指针不恒等被证实为平台特有问题。8/8 轮 host
  命中 4223/4224，L2 reload TTFT 24.4ms vs 冷 prefill 65.1ms，配对 R/P
  中位 0.375（WSL2 基线为 0.215，跨硬件仅并列展示）。工具链偏离全部记录：
  驱动 550 卡死 cu13 路径（cuda-compat 消费卡被拒 Error 804），改用
  torch 2.11+cu128 + sgl-kernel 源码构建（sm_89 裁剪，补丁留档）；host
  pool 受容器 cgroup 96GiB 约束收缩至 0.40/2.0。
- **meta 同步**：证据索引新增三个入口；README 与毕业门槛、审计路线图的
  对应段落同步到新事实。ncu 权限、torch pinned 版本兼容、跨仓公平基线、
  多卡与生产 SLO 保持开放。
